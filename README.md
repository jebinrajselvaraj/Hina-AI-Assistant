# 🤖 Hina: Personal AI Desktop Assistant

> A Jarvis-style AI assistant for Windows with a talking avatar, emotions, and Tamil + English voice control.

![Status](https://img.shields.io/badge/status-in%20progress-orange) ![Platform](https://img.shields.io/badge/platform-Windows-blue) ![Python](https://img.shields.io/badge/Python-3.x-blue)

## 📌 Overview
Hina is a personal AI assistant that runs on my laptop. You talk to her naturally, she replies with a voice and an animated avatar, reacts with emotions, and can carry out tasks on the computer for you.

## ✨ Features
- 🗣️ **Voice conversation** in **Tamil and English**
- 🎭 **Talking visual avatar** with emotion-responsive reactions
- 💻 **Laptop task control:** carries out tasks on Windows through spoken commands
- 💬 Short, natural dialogue designed to feel like a real assistant
- 🏠 Runs locally on the desktop
